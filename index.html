Preciso de engenharia para ligar os eventos?

SDKs e webhooks no Growth+. O onboarding mapeia as fontes com o time — demo sem backend nesta biblioteca.

Onde ficam os dados?

Declare a região real na marca final. Este mock usa linguagem LGPD / SOC ilustrativa.

Dá para white-label?

No Scale, sim — tema, domínio e e-mails. Tokens CSS já estão separados em variables.css.
